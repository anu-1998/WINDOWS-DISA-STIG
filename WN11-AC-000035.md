# STIG Implementation & Vulnerability Remediation

## WN11-AC-000035 – Minimum Password Length Must Be Configured to 14 Characters

## 1. STIG Identification

- **STIG ID:** WN11-AC-000035
- **Vuln-ID:** V-253386
- **Rule-ID:** SV-253386r917906_rule
- **Severity Category:** CAT II
- **CCI:** CCI-000205
- **Audit Name:** DISA Windows 11 STIG v1r6
- **Plugin:** Windows
- **Control ID:** 8f2a1b3c4d5e6f7a8b9c0d1e2f3a4b5c6d7e8f9a0b1c2d3e4f5a6b7c8d9e0f1a

## 2. Overview

This document describes the detection, manual remediation, automation, and validation of STIG WN11-AC-000035 on Windows 11 endpoints using Tenable for vulnerability scanning.

**Purpose:** Enforce a minimum 14-character password length to increase resistance against brute force, dictionary, and rainbow table attacks. Short passwords are significantly easier to crack, compromising domain and local security.

**Process:** Detect → Fix → Verify → Revert → Automate → Re-verify

## 3. Detection (Tenable Scan)

- **Tool Used:** Tenable (Nessus / Tenable.io)
- **Scan Template:** Windows / DISA STIG Compliance Scan

**Initial Scan Result:**

- ❌ **FAILED**
- **STIG ID:** WN11-AC-000035
- **Severity:** Medium (CAT II)
- **Finding:** The 'Minimum password length' policy is either not configured or set to less than 14 characters.

## 4. Research & Analysis

- **Reference:** Official DISA STIG Viewer and Microsoft Security Compliance Toolkit.
- **Policy Path:** Computer Configuration → Windows Settings → Security Settings → Account Policies → Password Policy
- **Policy Name:** Minimum password length
- **Required Setting:** `14` characters

## 5. Manual Remediation

**Method:** Local Group Policy Editor (`gpedit.msc`) or Domain Group Policy Management Console (GPMC) for domain-joined systems.

**Steps (Local Policy):**

1.  Open **Local Group Policy Editor** (`gpedit.msc`).
2.  Navigate to:  
    `Computer Configuration` → `Windows Settings` → `Security Settings` → `Account Policies` → `Password Policy`
3.  Locate the policy: **Minimum password length**.
4.  Set the value to **`14`** characters.
5.  Click **Apply** and **OK**.
6.  Run `gpupdate /force` in Command Prompt as Administrator to refresh policy.
7.  No restart is required, but a logoff/logon cycle is recommended for new passwords.

## 6. Verification (Manual Fix)

- System updated with `gpupdate /force`.
- Tenable scan rerun against the target system.

## 8. PowerShell Remediation

**Objective:** Automate WN11-AC-000035 remediation using PowerShell (requires administrative privileges).

```powershell
# WN11-AC-000035 Remediation Script
# Set Minimum Password Length to 14 characters

# Define the registry path and value
$RegPath = "HKLM:\SYSTEM\CurrentControlSet\Services\Netlogon\Parameters"
$RegValueName = "MinimumPasswordLength"
$RequiredLength = 14

# Apply the setting
Write-Host "Applying STIG WN11-AC-000035..."
Set-ItemProperty -Path $RegPath -Name $RegValueName -Value $RequiredLength -Type DWord -Force

# Verify application
$CurrentValue = (Get-ItemProperty -Path $RegPath -Name $RegValueName).$RegValueName

if ($CurrentValue -eq $RequiredLength) {
    Write-Host "SUCCESS: Minimum Password Length set to $RequiredLength characters." -ForegroundColor Green
} else {
    Write-Host "FAILURE: Unable to set Minimum Password Length. Value is $CurrentValue." -ForegroundColor Red
}

# Update Group Policy
Write-Host "Updating Group Policy..."
gpupdate /force
Write-Host "Remediation script completed."
